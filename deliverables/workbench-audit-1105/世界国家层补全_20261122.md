# 旅行地图 · 世界国家层补全执行报告（v25）

- 日期：2026-11-22
- 触发：用户「旅行地图的世界地图的国家不全吧」
- 结论：确实不全——原为 22 个精选目的地，约占主权国家总数 11%。已补全为 **194 个**（195 主权国家扣掉中国本身），城市 46 → 146，并顺带修掉一个会让日记串档的既存缺陷。
- 版本：`APP_CACHE` v24 → **v25**

## 一、问题核实

`旅行地图.html` 第 430–501 行（改前）只有 22 国 46 城：

| 亚洲 | 日、韩、新、泰、马、印尼、越 | 印度、菲律宾、柬埔寨、老挝、缅甸、尼泊尔、斯里兰卡、马尔代夫、沙特、以色列、卡塔尔 |

## 三、改动清单

### 3.1 数据

- `WORLD_COUNTRIES`：22 → 194 条，字段扩为 `{id,name,en,ct,lat,lng}`——`en` 供英文搜索，`ct` 供大洲分组。
- `WORLD`：46 → 146 条，字段扩 `en`。**原有 46 个城市 id 逐字保留**（tokyo/osa/…/rio），已点亮记录不受影响。
- 原有 22 个国家 id 全部保留（jp/kr/sg/th/my/id/vn/gb/fr/it/de/ch/es/ru/tr/ae/eg/us/ca/au/nz/br），与 ISO 3166-1 alpha-2 一致。

### 3.2 国家模式 UI

### 3.3 顺带修复：日记外键串档（既存缺陷）

`CHINA` / `CN_CITIES` 的 id 与 ISO 国家码有 **33 处撞车**：

```
省级：bj(贝宁) sd(苏丹) sn(塞内加尔) fj(斐济) hn(洪都拉斯) gd(格林纳达) sc(塞舌尔) tj(塔吉克)
城市：es(恩施/西班牙) sg(韶关/新加坡) my(绵阳/马来西亚) pt(莆田/葡萄牙) ly(利比亚) bh(巴林)
      dz(阿尔及利亚) ls(莱索托) gy(圭亚那) lb(黎巴嫩) km(科摩罗) sl(塞拉利昂) al(阿尔巴尼亚)
      gn(几内亚) zw(津巴布韦) ht(海地) tn(铜仁/突尼斯) bd(孟加拉) py(巴拉圭) bt(不丹)
      cf(中非) sy(叙利亚) mh(马绍尔) sz(斯威士兰) tz(坦桑尼亚)
```

而 `findPlace()` 是 `concat(CHINA,CN_CITIES,WORLD_COUNTRIES,WORLD).find(x=>x.id===pid)`，取第一个命中。后果：**给西班牙写的地点日记，恩施的「日记 N」按钮也会 +1**；打开恩施的日记会看到西班牙的游记。改前 46 个城市时 sg/my/es 就已经撞，只是没人给这几个地方写过日记所以没暴露。

修法：

1. 给每张表条目挂带表前缀的唯一键 `k`：`c:` 省份 / `cc:` 中国城市 / `w:` 国家 / `wc:` 世界城市。日记的 `placeId` 只认 `k`；`state` 四个 bucket 仍存裸 id，**与历史 localStorage 完全兼容**。
2. `migrateDiaryKeys()` 在首次 `refreshCounts()` 前跑一次，按**当年的查找顺序**（CHINA→CN_CITIES→WORLD_COUNTRIES→WORLD）判定裸 id 归属。所以 `es` 仍然归恩施——迁移不改变任何已显示的历史结果，只消除歧义。幂等，已带前缀的跳过。

## 五、边界与诚实披露

1. **小国标记仍会重叠**：点亮是中心点 Marker，不是国界填色（用户此前明确决定不做填色）。欧洲微型国家（列支敦士登、圣马力诺、摩纳哥、安道尔、梵蒂冈）在 zoom 3 下间距不足 20px，直接点地图大概率点到邻国。**缓解手段是搜索后自动定位**，清单点击永远可用。
2. **109 个国家没有城市**：城市层只收旅行热点（146 个覆盖 85 国），不追求每国都有首都。若需要，可按同一结构补到 255 个（每国至少一个首都），但会让城市模式的分组头从 85 涨到 194，浏览体验变差，故未做。
3. **坐标是中心点近似值**：大国取地理中心，小国取近似中心，误差对小国 marker 位置有几百公里级偏差（在地图视觉上不明显，但若将来做距离计算不能直接用）。
4. **不含海外领地**：去关岛、大溪地、格陵兰、波多黎各无法在世界国家层点亮。如需支持，应新增独立的「地区」分层，不要混进国家列表。
5. **`state` 里残留的脏 id 不会自动清理**：`updateStat` 用 `state[bucket()].length` 计已点亮数，若历史 localStorage 里有已不存在的 id（例如将来删除某国），分子会偏大。当前 194 国是现有 22 国的超集，不会触发。
6. **迁移是单向的**：旧日记迁移后 placeId 变 `c:/cc:/w:/wc:` 前缀。若回退到 v24 及更早版本，页面会把带前缀的 placeId 当作未知地点，日记按钮不再计数（数据本身不丢，只是显示不出）。回退需同时清 localStorage 里的日记库或手工改回裸 id。
7. **未做的优化**：低 zoom 时按大洲聚合标记（需要 TMap 聚合簇 API，`1.exp` 版本支持情况未验证，不做未验证的 API 调用）；拼音首字母搜索（如输入 `pt` 找葡萄牙靠 ISO 码已覆盖，输入 `xby` 找西班牙不支持）。
