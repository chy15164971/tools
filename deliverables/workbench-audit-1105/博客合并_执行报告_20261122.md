## 二、新增页面

### 作品集.html
- 数据键 `wb_portfolio_v1`：**全量快照 + 删除墓碑**模式（`{seedVer, items, del, ts}`）——首次运行种入内置九件并立即落盘，时间线才能读到作品事件；未来内置扩充通过升 `SEED_VER` 补种（已删除的经墓碑防复活）。
- 功能：分类筛选 chips（全部/设计/摄影/插画，自定义新分类自动补 chip）、网格卡片、lightbox 大图（左右键翻页 + Esc 关闭 + 焦点回环）、编辑信息、删除（内置件进墓碑）、添加自定义条目（站内相对路径或外链 URL）、导出/导入 JSON。
- 图片本体在 `assets/portfolio/`，localStorage 只存元数据，无配额风险。

### 随笔.html
- 数据键 `wb_notes_v1`：文章数组（`{id,title,md,tags,createdAt,updatedAt}`）。
- 功能：文章列表 + 搜索（标题/正文/标签）、页内 Markdown 编辑器（编辑/预览双 tab）、阅读弹窗、删除带确认、导出/导入 JSON。
- Markdown 渲染器**安全实现**：全文先转义再做语法替换；链接/图片 URL 过滤 scheme（只放行 http(s)/mailto/相对路径，拦 `javascript:`/`data:` 等）；专项测试含 XSS 三连断言（script 标签 / onerror / javascript: 链接均不成活）。
- v1 未接 Gist 云同步（各页同步形态不一，硬接风险大于收益），以导出/导入 JSON 作备份迁移手段——诚实披露，后续可评估接入。
