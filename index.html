分类与优先级

改名会自动同步已有任务；删除时若仍有任务在用，会让你选择迁移目标。每组至少保留 1 项。若改名后仍有任务留着旧名称，它们会作为「遗留值」出现在下方，可一键合并到现行名称。

这些名称已不在上面的列表里，但仍挂在任务上（统计里会单独占一行）。选好目标后点「合并」，相关任务会改挂到现行名称，可用 Ctrl+Z 撤销。

标签管理

标签支持「父标签 / 子标签」两级。打开本页会自动汇总任务中已使用的标签（无需逐个手动添加），数字为该标签被多少任务使用。删除父标签时，相关任务的该标签会被移除（子标签一并移除）。若要把两个标签统一成一个，点行内的 ⇄ 合并，相关任务的标签会自动改成目标标签。

👋 欢迎使用任务管理台

一个页面管住任务、项目、OKR、清单、习惯、纪念日与媒体进度。挑常用的用就好，不用一次全开。

  • ✅
    任务 / 清单：日常待办与「待读图书」「待寄明信片」这类收集箱
  • 🎯
    项目 / OKR：把大目标拆成可追踪的关键结果
  • 📅
    纪念日 / 习惯：农历倒计时与每日打卡
  • 📊
    媒体进度：读书 / 剧集按页、集或百分比自定义单位
  • ☁️
    云同步：配置 GitHub Gist 后多端无缝衔接（可选）
